# Repeated_Harmony

Source codes for "Symmetric solution of the Bellman optimality equation for repeated harmony game".

The versions of Python and the key libraries used in the calculations in this paper are as follows:

Python 3.11.10

NumPy 1.26.0

(Matplotlib 3.9.2 , pandas 2.2.3 : used only for visualization)
